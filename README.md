# THE DAILY ATLAS — The World in One Day, Friday 20 November 2026

A gazetteer-style news page: the whole of Friday 20 November 2026 on one 1024x1024 picture, drawn like an atlas plate on parchment with forest-green and burgundy ink.

- All 40 stories happened, or were first reported, on Friday 20 November 2026 — 13 pictured stories plus 27 briefs, across 7 regions.
- Every story carries its source beside it: a source tag on each illustrated strip and the source in brackets at the end of each brief.
- The bottom half is a real map: country polygons plotted from longitude/latitude data, numbered pins for the 13 pictured stories, small dots for the briefs, and an exit arrow for the one story that left the planet (BepiColombo at Mercury).
- A UTC timeline, a "Day in Numbers" strip and a region-count strip frame the page; a DATE CHECK box names the Thursday stories deliberately left out.
- Original drawings throughout: every illustration is a flat geometric scene drawn by the program itself — no photographs, no AI images, no network.
- Deterministic: `draw.py` (Python stdlib + Pillow only) renders `entry.png` identically on every run; `main.py` copies it to the output directory.
